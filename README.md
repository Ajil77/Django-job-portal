Job Portal — Django Web Application

A full-featured Job Portal built with Django, connecting employers and job seekers.
Employers can post jobs, and job seekers can apply, upload resumes, and manage their profiles — all within a simple, responsive interface.
🌟 Features

 Employer Features
- Register, log in, and manage a profile.
- Post new job listings with descriptions.
- View and download applicants’ resumes.
- Manage active job postings.

 Job Seeker Features
- Create and update a professional profile.
- Upload a resume (PDF format).
- Search and filter available jobs.
- Apply directly to job listings.

 Admin Features
- Access the Django admin panel.
- Manage all users, jobs, and applications.
Tech Stack

|Layer | Technology 
Backend | Python 3.11, Django 4.x |
 Frontend | HTML5, CSS3 BOOSTRAP5|
Database | SQLite3 |
Server | WSGI / ASGI |
Media Storage | Django Media (for resumes and company logos) |

Usage Guide

Register as Employer or Job Seeker
Log in to access your respective dashboard.
Employers → Post jobs, view applicants.
Job Seekers → Search jobs, apply with uploaded resumes.
Admins → Manage all users and content via Django Admin.
